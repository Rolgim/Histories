# Contributing

Merci de contribuer au projet.

## Contenu historique

Les contributions de contenu doivent rester dans `data/`. Une contribution devrait idéalement ajouter un nouveau fichier plutôt que modifier un gros fichier partagé.

## Merge Requests

La CI vérifie la syntaxe JSON et les schémas. Les changements historiques sont ensuite relus humainement avant fusion.

## Code

Les modifications de `src/` doivent être réservées aux changements du moteur de visualisation, de l’interface ou des fonctionnalités techniques.
